# Справочник API приложения Visage Studio

## Обзор

Данный документ описывает внутренние функции и API, используемые в приложении Visage Studio.

## Глобальные переменные

### `state`
Объект, хранящий текущее состояние приложения:

```javascript
{
  templateId: string,        // ID текущего шаблона
  intensity: number,         // Интенсивность макияжа (0-1)
  scale: number,             // Масштаб шаблона (0.5-1.8)
  rotation: number,          // Угол поворота (градусы)
  warmth: number,            // Баланс оттенка (-1 to 1)
  exposure: number,          // Экспозиция (-0.5 to 0.5)
  offset: { x: number, y: number }, // Смещение макияжа
  variantId: string,         // ID текущего варианта оттенка
  hintDismissed: boolean     // Отображалось ли руководство
}
```

### `templates`
Массив шаблонов макияжа, определенных в `templates.js`.

## Функции

### `buildTemplateCards()`
Создает карточки шаблонов в интерфейсе.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Создает кнопки для всех шаблонов и добавляет их в список выбора шаблонов.

---

### `setupVariantInteractions()`
Настройка обработчиков событий для вариантов оттенков.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Устанавливает обработчики кликов для выбора вариантов оттенков.

---

### `selectTemplate(templateId, options)`
Выбирает шаблон макияжа.

**Параметры:**
- `templateId` (string): ID шаблона для выбора
- `options` (object): Опции выбора
  - `reset` (boolean, optional): Сбросить параметры к значениям по умолчанию (по умолчанию false)
  - `silent` (boolean, optional): Подавить вывод сообщений (по умолчанию false)

**Возвращает:** void  
**Описание:** Устанавливает указанный шаблон как активный и обновляет интерфейс.

---

### `updateTemplateCards()`
Обновляет отображение карточек шаблонов.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Обновляет статус активности карточек шаблонов в соответствии с текущим состоянием.

---

### `updateVariantPanel()`
Обновляет панель вариантов оттенков.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Обновляет список и отображение вариантов оттенков для текущего шаблона.

---

### `updateVariantActiveState()`
Обновляет активное состояние кнопок вариантов оттенков.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Обновляет визуальное состояние кнопок вариантов оттенков.

---

### `updateVariantDescription()`
Обновляет описание текущего варианта оттенка.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Отображает описание текущего выбранного варианта оттенка.

---

### `updateTemplateMeta()`
Обновляет метаданные текущего шаблона.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Обновляет отображение названия, описания и тегов текущего шаблона.

---

### `updateControlsFromState()`
Обновляет элементы управления из состояния.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Синхронизирует значения ползунков управления с текущим состоянием.

---

### `initializeCanvas()`
Инициализирует canvas для отображения макияжа.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Настраивает canvas и наблюдатель за изменением размеров.

---

### `renderAll()`
Выполняет полную перерисовку интерфейса.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Перерисовывает оверлей макияжа и обновляет фильтры изображения.

---

### `drawOverlay()`
Рисует оверлей макияжа на canvas.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Рисует все слои макияжа с учетом текущих параметров и трансформаций.

---

### `drawLayer(context, layer, width, height, color)`
Рисует один слой макияжа.

**Параметры:**
- `context` (CanvasRenderingContext2D): 2D контекст canvas
- `layer` (object): Определение слоя
- `width` (number): Ширина canvas
- `height` (number): Высота canvas
- `color` (string): Цвет слоя

**Возвращает:** void  
**Описание:** Рисует один слой (эллипс или прямоугольник) на canvas.

---

### `resolveLayerColor(layer, variant)`
Определяет цвет слоя на основе варианта оттенка.

**Параметры:**
- `layer` (object): Определение слоя
- `variant` (object): Вариант оттенка

**Возвращает:** string|null - Цвет слоя или null если не может быть определен

---

### `resolveLayerOpacity(layer, variant)`
Определяет прозрачность слоя на основе варианта оттенка.

**Параметры:**
- `layer` (object): Определение слоя
- `variant` (object): Вариант оттенка

**Возвращает:** number - Значение прозрачности (0-1)

---

### `updateImageFilter()`
Обновляет CSS фильтры изображения.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Применяет фильтры яркости, контраста, насыщенности и оттенка к изображению.

---

### `handleUpload(event)`
Обрабатывает загрузку изображения пользователем.

**Параметры:**
- `event` (Event): Событие изменения input

**Возвращает:** void  
**Описание:** Обрабатывает загрузку пользовательского изображения и обновляет интерфейс.

---

### `handlePhotoLoad()`
Обрабатывает загрузку изображения.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Обновляет соотношение сторон и выполняет необходимые действия после загрузки изображения.

---

### `onPointerDown(event)`
Обработчик начала перетаскивания.

**Параметры:**
- `event` (PointerEvent): Событие указателя

**Возвращает:** void  
**Описание:** Инициализирует состояние перетаскивания.

---

### `onPointerMove(event)`
Обработчик движения во время перетаскивания.

**Параметры:**
- `event` (PointerEvent): Событие указателя

**Возвращает:** void  
**Описание:** Обновляет смещение макияжа во время перетаскивания.

---

### `onPointerUp()`
Обработчик завершения перетаскивания.

**Параметры:** Нет  
**Возвращает:** void  
**Описание:** Завершает состояние перетаскивания.

---

### `setStatus(message, status)`
Устанавливает статусное сообщение.

**Параметры:**
- `message` (string): Текст сообщения
- `status` (string, optional): Статус ('success', 'warning', и т.д.)

**Возвращает:** void  
**Описание:** Отображает статусное сообщение пользователю.

---

### `getCurrentTemplate()`
Получает текущий шаблон.

**Параметры:** Нет  
**Возвращает:** object|null - Текущий шаблон или null если не найден

---

### `getCurrentVariant()`
Получает текущий вариант оттенка.

**Параметры:** Нет  
**Возвращает:** object|null - Текущий вариант оттенка или null если не найден

---

### `applyTemplateDefaults(template)`
Применяет значения по умолчанию для шаблона.

**Параметры:**
- `template` (object): Шаблон для применения значений

**Возвращает:** void  
**Описание:** Устанавливает параметры состояния в значения по умолчанию для указанного шаблона.

---

### `createTemplateDefaults(template)`
Создает значения по умолчанию для шаблона.

**Параметры:**
- `template` (object): Шаблон для которого создаются значения

**Возвращает:** object - Объект с параметрами по умолчанию

---

### `clamp(value, min, max)`
Ограничивает значение диапазоном.

**Параметры:**
- `value` (number): Значение для ограничения
- `min` (number): Минимальное значение
- `max` (number): Максимальное значение

**Возвращает:** number - Ограниченное значение

---

### `formatIntensity(value)`
Форматирует значение интенсивности для отображения.

**Параметры:**
- `value` (number): Значение интенсивности

**Возвращает:** string - Отформатированное значение (например, "85%")

---

### `formatScale(value)`
Форматирует значение масштаба для отображения.

**Параметры:**
- `value` (number): Значение масштаба

**Возвращает:** string - Отформатированное значение (например, "100%")

---

### `formatRotation(value)`
Форматирует значение поворота для отображения.

**Параметры:**
- `value` (number): Значение поворота

**Возвращает:** string - Отформатированное значение (например, "+5°")

---

### `formatWarmth(value)`
Форматирует значение теплоты для отображения.

**Параметры:**
- `value` (number): Значение теплоты

**Возвращает:** string - Отформатированное значение (например, "+15°")

---

### `formatExposure(value)`
Форматирует значение экспозиции для отображения.

**Параметры:**
- `value` (number): Значение экспозиции

**Возвращает:** string - Отформатированное значение (например, "+5%")
