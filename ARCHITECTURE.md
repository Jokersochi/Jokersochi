# Архитектура приложения Visage Studio

## Общее описание

Visage Studio - это одностраницное веб-приложение (SPA), реализованное на чистом JavaScript без использования сторонних фреймворков. Приложение позволяет пользователям загружать свои фотографии и применять к ним различные шаблоны виртуального макияжа.

## Структура проекта

```
/workspace/
├── index.html              # Входная точка приложения
├── src/
│   ├── main.js            # Основная логика приложения
│   ├── templates.js       # Определение шаблонов макияжа
│   ├── style.css          # Стили приложения
│   └── assets/
│       └── demo-face.svg  # Демонстрационное изображение
├── package.json           # Зависимости и скрипты
├── vite.config.js         # Конфигурация сборки
├── sw.js                  # Service Worker для PWA
└── manifest.json          # Манифест PWA
```

## Архитектурные компоненты

### 1. Управление состоянием (State Management)

Приложение использует простую систему управления состоянием на основе объекта `state`:

```javascript
const state = {
  templateId: primaryTemplate.id,
  intensity: 0.85,
  scale: 1,
  rotation: 0,
  warmth: 0,
  exposure: 0,
  offset: { x: 0, y: 0 },
  variantId: null,
  hintDismissed: false
};
```

### 2. Управление шаблонами (Template Management)

Шаблоны макияжа определены в `templates.js` и содержат:

- Информацию о слоях макияжа (оверлеях)
- Варианты оттенков
- Настройки по умолчанию
- CSS фильтры
- Теги и описания

### 3. Отображение (Rendering)

Отображение осуществляется через:

- HTML DOM для интерфейса
- Canvas API для наложения макияжа
- CSS для стилизации и анимаций

### 4. Взаимодействие с пользователем (User Interaction)

Приложение обеспечивает следующие виды взаимодействия:

- Загрузка изображений
- Выбор шаблонов макияжа
- Настройка параметров (интенсивность, масштаб, поворот и т.д.)
- Перетаскивание элементов макияжа
- Выбор вариантов оттенков

## Основные функции

### 1. `drawOverlay()` - отрисовка макияжа

Функция отвечает за отрисовку всех слоев макияжа на canvas:

- Применяет трансформации (масштаб, поворот, смещение)
- Рассчитывает цвета и прозрачность слоев
- Применяет фильтры и эффекты

### 2. `updateImageFilter()` - коррекция изображения

Функция применяет CSS фильтры к основному изображению:

- Яркость
- Контраст
- Насыщенность
- Цветовой баланс

### 3. `handleUpload()` - загрузка изображений

Функция обрабатывает загрузку пользовательских изображений:

- Проверяет формат файла
- Создает объектный URL для безопасного доступа
- Обновляет интерфейс

### 4. `onPointerDown/Mouse/Up` - перетаскивание

Функции обеспечивают интерактивное перемещение элементов макияжа:

- Отслеживают события указателя
- Рассчитывают смещение
- Обновляют состояние и перерисовывают

## Архитектурные паттерны

### 1. MVC (Model-View-Controller)

- **Model**: объект `state` и шаблоны макияжа
- **View**: HTML DOM и Canvas
- **Controller**: функции в `main.js` обрабатывающие события

### 2. Observer (Наблюдатель)

Интерфейсные элементы реагируют на изменения состояния:

- Изменения в input-элементах обновляют `state`
- Изменения `state` вызывают перерисовку

### 3. Singleton

Объект `state` является единственным источником истины для всего приложения.

## Безопасность и производительность

### Безопасность

- Использование `URL.createObjectURL()` для безопасной загрузки изображений
- Проверка формата файлов при загрузке
- Sanitization данных шаблонов

### Производительность

- Использование `ResizeObserver` для оптимизации рендеринга
- Оптимизация перерисовки через `devicePixelRatio`
- Использование GPU-accelerated CSS свойств

## PWA возможности

- Service Worker для кэширования и офлайн работы
- Манифест для установки как приложения
- Push-уведомления (реализованы в service worker)

## Расширяемость

Приложение спроектировано для легкого добавления новых шаблонов макияжа:

1. Добавление нового объекта в массив `templates`
2. Определение слоев и вариантов
3. Настройка фильтров и параметров по умолчанию

## Тестирование

Приложение включает модульные тесты для различных компонентов:

- Тесты для логики работы с состоянием
- Тесты для вспомогательных функций
- Тесты для работы с шаблонами
