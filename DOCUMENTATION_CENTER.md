# 📚 Центр документации Visage Studio

## Обзор проекта

**Visage Studio** - это современное веб-приложение для виртуальной примерки макияжа, позволяющее пользователям загружать свои фотографии и пробовать различные шаблоны макияжа онлайн.

## Архитектурные особенности

### Основные компоненты
1. **Шаблоны макияжа** (`templates.js`) - определение всех шаблонов и их параметров
2. **Управление состоянием** (`state`) - централизованное управление данными приложения
3. **Рендеринг** - комбинация Canvas API и CSS фильтров
4. **Интерфейс** - чистый HTML с современными CSS стилями

### Паттерны проектирования
- **MVC** - разделение модели, представления и контроллера
- **Observer** - реактивное обновление интерфейса при изменении состояния
- **Singleton** - централизованное состояние приложения

## Функциональность

### Основные возможности
- 🖼️ Загрузка пользовательских фотографий
- 🎭 Три основных стиля макияжа с вариантами оттенков
- ⚙️ Настройка интенсивности, масштаба, поворота и оттенков
- 🖱️ Интерактивное перетаскивание элементов макияжа
- 📱 Адаптивный дизайн для всех устройств
- 🔄 Поддержка PWA (Progressive Web App)

### Технологии
- **JavaScript (ES6+)** - основной язык программирования
- **Canvas API** - для отображения макияжа
- **CSS3** - стилизация и анимации
- **Vite** - система сборки
- **PWA** - поддержка офлайн работы

## Расширение функциональности

### Добавление новых шаблонов
1. Определите новый шаблон в `templates.js`
2. Укажите слои макияжа (оверлеи)
3. Настройте варианты оттенков
4. Определите фильтры и параметры по умолчанию

### Добавление новых функций
- Расширьте объект `state` новыми параметрами
- Добавьте соответствующие элементы управления в HTML
- Обновите функции рендеринга при необходимости

## Безопасность и производительность

### Безопасность
- Использование `URL.createObjectURL()` для безопасной загрузки изображений
- Проверка формата файлов при загрузке
- Sanitization данных шаблонов

### Производительность
- Оптимизация рендеринга через `ResizeObserver`
- Использование GPU-accelerated CSS свойств
- Эффективное управление памятью при работе с изображениями
