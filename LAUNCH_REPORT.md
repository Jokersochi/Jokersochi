## Примечания

### Ограничения текущего запуска
⚠️ **Важно**: Приложения использует ES6 модули и импорты ресурсов через Vite. Для полной функциональности в production требуется:
1. Установка зависимостей: `npm install`
2. Сборка через Vite: `npm run build`
3. Использование Vite dev-сервера: `npm run dev`

### Текущие ограничения
- Модульная система может не работать корректно без proper MIME-types
- Импорт ресурсов (CSS, изображения) требует сборщика
- Для локальной разработки рекомендуется использовать Vite

### Рекомендации для production
```bash
# Установить зависимости
npm install

# Запустить development сервер с горячей перезагрузкой
npm run dev

# Или собрать production версию
npm run build
npm run preview
```
