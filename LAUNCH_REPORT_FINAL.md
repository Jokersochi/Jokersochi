### Как использовать:

1. **Откройте браузер** и перейдите по адресу: http://localhost:8080

2. **Загрузите фотографию** или используйте демо-изображение

3. **Выберите шаблон макияжа** из доступных вариантов

4. **Настройте параметры**:
   - Тон кожи
   - Тени для век
   - Цвет губ
   - Интенсивность эффектов

5. **Сохраните результат** или поделитесь им

### Технические детали:

#### Доступные эндпоинты:
- `GET /` - Главная страница приложения
- `GET /src/main.js` - Основной JavaScript файл
- `GET /src/style.css` - Стили приложения
- `GET /src/templates.js` - Шаблоны макияжа
- `GET /src/assets/*` - Ресурсы (изображения, SVG)
