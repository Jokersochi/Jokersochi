# Структура проекта Visage Studio

## Обзор

Этот репозиторий содержит веб-приложение "Visage Studio" - виртуальную примерочную макияжа, а также различные сопутствующие проекты и инструменты.

## Основные компоненты

### 1. Visage Studio (основное приложение)

**Файлы:**
- `/index.html` - основной HTML-файл
- `/src/main.js` - основной JavaScript файл приложения
- `/src/style.css` - стили приложения
- `/src/templates.js` - шаблоны макияжа
- `/src/assets/demo-face.svg` - демо-изображение

**Функциональность:**
- Загрузка пользовательских фото
- Примерка различных шаблонов макияжа
- Настройка интенсивности, масштаба, поворота и оттенков
- Интерактивное перетаскивание элементов макияжа

### 2. Конфигурационные файлы

- `/package.json` - зависимости и скрипты
- `/vite.config.js` - конфигурация сборки
- `/sw.js` - сервис-воркер для PWA функциональности
- `/manifest.json` - манифест PWA

### 3. Дополнительные проекты

#### Make up Sochi
- `/Make up Sochi/` - каталог мероприятий по макияжу в Сочи

#### Calorie Tracker
- `/apps/calorie-tracker/` - приложение для отслеживания калорий

#### Virtual Makeup (Python)
- `/apps/virtual_makeup/makeup_app.py` - Python приложение для виртуального макияжа

### 4. Улучшения и укрепления

#### Hardening Pack v1
- `/jokersochi-hardening-pack-v1/` - улучшения безопасности и качества кода

#### Improvement Pack v2
- `/jokersochi-improvement-pack-v2/` - улучшения SEO, производительности и карты сайта

### 5. Инструменты

- `/Parse-SobytiyaLog.ps1` - PowerShell скрипт для парсинга логов
- `/Parse-SobytiyaLog.Tests.ps1` - тесты для скрипта парсинга логов

### 6. Скрипты

- `/scripts/` - вспомогательные скрипты (оптимизация изображений, SVG, генерация архивов)

## Архитектура основного приложения

### Основные компоненты

1. **Шаблоны макияжа** (`templates.js`)
   - Три основных типа: "Нежное сияние", "Вечерняя драма", "Цветовой акцент"
   - Каждый шаблон имеет настраиваемые параметры и вариации

2. **Интерфейс** (`main.js`)
   - Загрузка фото
   - Настройки интенсивности, масштаба, поворота
   - Панель выбора шаблонов и вариаций
   - Канвас для отображения макияжа

3. **Стили** (`style.css`)
   - Современный дизайн с градиентами
   - Адаптивная верстка
   - Поддержка темной/светлой темы

## Запуск проекта

```bash
npm install
npm run dev
```

## Сборка проекта

```bash
npm run build
```

## Особенности реализации

- Использование Canvas API для наложения макияжа
- Интерактивное перетаскивание элементов
- Поддержка PWA
- Адаптивный дизайн
- Поддержка различных вариаций оттенков
