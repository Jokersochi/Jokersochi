# 🎨 Visage Studio - Виртуальная примерочная макияжа

## Описание проекта

**Visage Studio** - это современное веб-приложение для виртуальной примерки макияжа, позволяющее пользователям загружать свои фотографии и пробовать различные шаблоны макияжа онлайн.

## Особенности

- 🖼️ Загрузка пользовательских фотографий
- 🎭 Три основных стиля макияжа: "Нежное сияние", "Вечерняя драма", "Цветовой акцент"
- ⚙️ Настройка интенсивности, масштаба, поворота и оттенков
- 🖱️ Интерактивное перетаскивание элементов макияжа
- 📱 Адаптивный дизайн для всех устройств
- 🔄 Поддержка PWA (Progressive Web App)
- 🎨 Множество вариаций оттенков для каждого шаблона

## Техническая информация

### Архитектура

- **Frontend**: Чистый JavaScript с использованием Canvas API
- **Build System**: Vite
- **Стили**: CSS с переменными и адаптивной версткой
- **PWA**: Полная поддержка офлайн режима

### Структура файлов

```
├── index.html                 # Главная HTML страница
├── src/
│   ├── main.js               # Основная логика приложения
│   ├── style.css             # Стили приложения
│   ├── templates.js          # Шаблоны макияжа
│   └── assets/               # Ассеты (демо-изображение)
├── package.json              # Зависимости и скрипты
├── vite.config.js            # Конфигурация Vite
├── sw.js                     # Сервис-воркер для PWA
└── manifest.json             # Манифест PWA
```

### Шаблоны макияжа

Каждый шаблон включает:
- Группы элементов (тени, румяна, губы, подводка и т.д.)
- Возможность настройки интенсивности
- Несколько вариантов оттенков
- Фильтры для коррекции изображения

## Установка и запуск

```bash
# Установка зависимостей

# Запуск в режиме разработки
npm run dev

# Сборка проекта
npm run build

# Предварительный просмотр сборки
npm run preview
```

## Технологии

- **JavaScript (ES6+)**: Современный чистый JavaScript без фреймворков
- **Canvas API**: Для наложения эффектов макияжа
- **CSS3**: Адаптивные стили с переменными
- **Vite**: Быстрая система сборки
- **PWA**: Поддержка офлайн работы

## Структура данных шаблона

Каждый шаблон макияжа представлен в формате JSON и включает:

```javascript
{
  id: 'unique-template-id',
  name: 'Название шаблона',
  description: 'Описание шаблона',
  preview: 'CSS gradient для превью',
  defaultVariant: 'id-варианта по умолчанию',
  defaults: {
    intensity: 0.85,    // интенсивность по умолчанию
    scale: 1,           // масштаб по умолчанию
    rotation: 0,        // поворот по умолчанию
    // и другие настройки
  },
  filters: {            // CSS фильтры для коррекции изображения
    brightness: 1.03,
    contrast: 1.02,
    saturate: 1.12,
    warmth: 0.08
  },
  tags: ['теги'],
  overlays: [           // элементы макияжа
    {
      id: 'layer-id',
      group: 'shadow|blush|lips|liner|highlight|contour',
      type: 'ellipse|rect',
      x: 0.35,          // координаты (0-1)
      y: 0.36,
      rx: 0.16,         // радиусы (0-1)
      ry: 0.065,
      rotation: -14,    // угол поворота
      blur: 0.02,       // размытие
      opacity: 0.92,    // прозрачность
      color: '#2c9bd4', // цвет
      blend: 'screen'   // режим наложения
    }
  ],
  variants: [           // варианты оттенков
    {
      id: 'variant-id',
      name: 'Название варианта',
      description: 'Описание',
      preview: ['#hex', '#hex', '#hex'], // превью цветов
      roles: {          // переопределение цветов по группам
        shadow: '#5d3a7a',
        liner: '#221322',
        // и т.д.
      },
      intensity: {      // переопределение интенсивности по группам
        liner: 1.05,
        highlight: 0.45
      }
    }
  ]
}
```
