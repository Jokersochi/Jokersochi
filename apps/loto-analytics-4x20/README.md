# LotoOS `loto-analytics-4x20` — direct build

Самостоятельная версия без зависимости от Lovable.

## Реализовано

- Понятное русское описание под каждой стратегией: Случайная, Горячие 200, Холодные 200, Горячие 1000, Просроченные, Гибрид.
- После каждого сгенерированного билета показывается блок **«Почему выбраны эти числа»**.
- Объяснение считается из тех же данных и правил, которыми сформирован билет:
  - Random — честный случайный выбор без использования истории.
  - Hot 200 / Hot 1000 — фактическая частота и место числа в окне.
  - Cold 200 — фактическая частота и место среди самых редких.
  - Overdue — текущий перерыв, средний перерыв и отношение к среднему.
  - Hybrid — z-отклонение частоты, относительный перерыв и итоговый балл.
- Детерминированные стратегии ограничены одним билетом, чтобы не создавать искусственную «диверсификацию» с выдуманными причинами. Несколько билетов разрешены только для Random.
- Постоянное примечание: объяснение описывает правило отбора, а не прогноз выигрыша.
- Mobile-first layout без горизонтальной прокрутки текста объяснений.
- Серверная функция получает только завершённые тиражи официального архива `4x20`, проверяет 4+4 числа и диапазон 1–20. При ошибке/смене схемы возвращает безопасную ошибку и не подменяет данные.

## Проверки

Локально выполнены:

- `node --check app.js`
- `node --check lib/strategy.js`
- `node --check api/draws.js`
- 4/4 unit-теста — PASS

Тесты проверяют отсутствие обещаний выигрыша, соответствие объяснения фактически выбранным числам, корректные 4+4 числа, стратегические метрики и запрет искусственных вариантов для детерминированных стратегий.

Полный исходный пакет: `loto-analytics-4x20-direct.zip`.
