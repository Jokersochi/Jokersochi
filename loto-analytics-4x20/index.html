Что именно считает алгоритм

Стратегии — проверяемые правила отбора, а не обещание преимущества. Генератор объясняет каждое выбранное число.

Сгенерировать билет

По умолчанию включён портфель из пяти разных билетов с контролем перекрытий. Для одиночных детерминированных стратегий система не создаёт искусственные варианты.
