Что именно считает алгоритм

Стратегии — проверяемые правила отбора, а не обещание преимущества. Генератор объясняет каждое выбранное число.

Сгенерировать билет

Для детерминированных стратегий показывается один честный билет: система не придумывает «разные» основания ради количества. Несколько билетов доступны для случайной стратегии.
